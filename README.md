# 사진대지 만들기 (Photo Layout Maker)

사건 현장 사진을 A4 **사진대지**로 정리해 수사서류에 첨부하기 위한 웹 프로그램입니다.
설치·서버가 필요 없습니다. 아래 주소로 접속하거나, `index.html` 파일을 크롬/엣지로 열면 바로 사용할 수 있습니다.

**바로 사용: https://bandit1397.github.io/Photo-Layout-Maker/**

**사진은 외부로 전송되지 않으며** 모든 처리는 사용 중인 컴퓨터의 브라우저 안에서만 이루어집니다.

## 사용 방법

1. `index.html`을 더블클릭해 크롬 또는 엣지로 엽니다.
2. **전체 사진 수**를 입력합니다. 사진 수에 맞게 한 장의 배치가 자동으로 정해집니다.
   - 예: 4장 → 2×2 한 장 / 6장 → 2×3 한 장
3. 원하는 배치가 다르면 **배치 버튼**(1×1, 1×2, 2×2, 2×3, 3×2, 3×3 …)이나 가로·세로 칸 수를 직접 고릅니다.
   넘치는 사진은 자동으로 다음 장에 이어집니다.
   - 예: 6장을 2×2로 고르면 → 첫 장 4개 + 다음 장 2개
4. 사진 파일을 배지 위로 **끌어다 놓습니다**. 사진이 아무리 커도 칸 크기에 맞게 자동으로 맞춰집니다.
   - 여러 장을 한 번에 끌어다 놓으면 놓은 칸부터 차례로 들어가고, 칸이 모자라면 자동으로 늘어납니다.
   - [사진 여러 장 한꺼번에 넣기] 버튼으로 골라도 됩니다.
5. 왼쪽 [맨 위 제목] 칸이나 용지 위의 **제목**(기본: 사진대지 — 글자와 글자 크기 변경 가능), 배지별 **제목·사진 설명**을 클릭해 입력합니다.
   - ④ 배지 모양에서 배지 사이 간격(0~20mm), 사진 제목·사진 설명의 글자 크기, 설명 줄 수, 설명의 가로(왼쪽/가운데/오른쪽)·세로(위/가운데/아래) 정렬을 바꿀 수 있습니다.
   - A4 상단 여백은 1.5cm입니다. 제목 아래 여백(0~30mm)은 [맨 위 제목]에서, 좌우 여백(5~30mm, 기본 12mm)은 ① 사진 수와 배치에서 조절합니다.
   - 사진에 촬영일시(EXIF)가 있으면 설명란에 자동으로 기입됩니다(옵션).
6. 필요하면 **사진 위 표시** 도구로 화살표, 원, 사각형, ①②③ 번호, 글자, 자유선을 그립니다.
7. **[인쇄 / PDF로 저장]**을 누릅니다. 인쇄 창에서 "PDF로 저장"을 고르면 PDF가 됩니다.
   배율은 기본값(100%), 여백은 "없음"을 권장합니다.

## 사진 조정

사진 위에 마우스를 올리면 도구 버튼이 나타납니다.

| 동작 | 방법 |
|---|---|
| 확대 / 축소 | 마우스 휠, 또는 ＋ / － 버튼 |
| 위치 이동 | [✋ 이동] 도구 상태에서 사진을 끌기 |
| 맞춤 ↔ 채우기 | 맞춤: 사진 전체가 보임(잘림 없음) / 채우기: 칸을 가득 채움(일부 잘림) |
| 원위치 | 확대·이동을 처음 상태로 |
| ◀ ▶ | 앞·뒤 칸과 사진 순서 바꾸기 |
| 교체 / ✕ | 다른 사진으로 바꾸기 / 사진 빼기 |

## 사진 위 표시

- 화살표·원·사각형·펜: 사진 위에서 마우스를 누른 채로 끌어 그립니다.
- ① 번호: 클릭할 때마다 1, 2, 3… 번호가 차례로 붙습니다.
- 글자: 왼쪽 칸에 글자(예: "사건 발생 위치")를 입력한 뒤 사진 위를 클릭합니다.
- 지우개: 지울 표시를 클릭합니다. `Ctrl+Z`로 되돌릴 수 있습니다.
- 표시는 사진에 붙어 있어 사진을 확대·이동해도 같은 위치를 따라갑니다.
- **원본 사진 파일은 절대 수정되지 않습니다.** 표시는 인쇄본(PDF)에만 들어갑니다.

## 작업 저장

- [작업 파일 저장]: 사진·글·표시를 모두 담은 `.json` 파일로 저장합니다.
- [작업 파일 불러오기]: 저장한 파일을 열어 이어서 작업합니다.
- 작업 파일에는 사진이 들어 있으므로 사건 자료와 같은 수준으로 보관·관리하십시오.
